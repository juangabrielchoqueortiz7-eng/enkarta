# Manuel y Maya
Referencia: https://invitali.com/125-manuel-y-maya/?id=anpmOT
Muestra: /muestra/manuel-y-maya (full=1 omite entrada).
Variante independiente `designKey: manuel-y-maya`; base SQL dolcevita. Textos, secciones, cuatro carruseles, collage por filas, iglesia, ambos lados del sobre, sello, fondo, dos tiendas y colores reservados editables en ManuelMayaFields. Originales conservados en public/invitations/manuel-y-maya. Las animaciones y música usan la biblioteca local aportada en Iconos INVITALI; no se modifican los JSON. Se distinguen anillos (2025/07/boda.json) y pareja (2025/08/boda.json).
La referencia responde “Invitación no válida” para el ID aportado; la muestra utiliza confirmación demo sin transmitir respuestas. La invitación publicada usa el formulario contratado. El pie identifica Enkarta.

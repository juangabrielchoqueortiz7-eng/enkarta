# Dirección visual de las invitaciones

Las referencias de Invitali aportadas por el cliente fijan el objetivo: invitaciones claras, hermosas y con un recorrido bien armado. Se consultaron directamente Laura y Andrés, Annie y Micky, y Roly y Yeliana. Las dos primeras muestran un aviso de ID no válido en la zona personalizada; sus formularios no se utilizaron como evidencia de funcionamiento.

## Estructura editorial

1. Apertura y portada: nombres protagonistas, fotografía, fecha completa y ciudad.
2. Fecha y calendario: un único dato de fecha consistente con el evento.
3. Bienvenida, invitado y familia: mensaje breve y pases legibles.
4. Lugares: tipo de ceremonia, hora, nombre del lugar y acción para llegar.
5. Vestimenta y programa: instrucciones directas y horarios en orden de lectura.
6. Fotografías y detalles opcionales: contenido real, sin capítulos vacíos.
7. Regalos y confirmación: cierre cálido y una acción principal reconocible.

## Acabado

- Reservar la letra manuscrita para los nombres y acentos emocionales; usar tipografía de lectura para instrucciones, horarios y botones.
- Mantener contraste en la información práctica; el dorado funciona como ornamento.
- Dar espacio entre capítulos, limitar el ancho de lectura y alinear acciones dentro de tarjetas.
- Mantener las fotografías y la identidad propia de cada colección; no reutilizar fotos ni recursos de las invitaciones de terceros.
- Comprobar navegación, legibilidad y ausencia de desbordamiento en móvil, además del escritorio.

## Aplicado en esta revisión

La escala compartida de texto y espaciado mejora las colecciones que usan `TYPE` y `SECTION`. Las tarjetas de lugares del constructor tienen jerarquía, marco y acciones alineadas. Oliva (implementación `DolceVita`) incorpora portada con fecha y ciudad, guía de navegación, tarjetas de lugares, programa vertical y cierre de confirmación.

Esto no equivale a un rediseño individual de todas las colecciones. Las composiciones particulares de las demás plantillas se conservan. No se modificaron datos de invitaciones ni se publicó una versión en producción.
